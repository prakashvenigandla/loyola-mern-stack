# Module 1: Programming Fundamentals & Web Development Basics  
## Classroom Activities 
### Activity 1: How the Internet Works 
Students simulate the interaction between a browser, server, and database to understand how requests are processed and responses are returned. 
Activity 2: Logic Building Challenge 
Students solve progressively complex logical problems using flowcharts and pseudocode before implementing them in code. 
Activity 3: Real-world Scenario Mapping 
Students identify common applications they use daily and map their frontend, backend, and database components. 
## Take-Home Assignment 
Personal Expense Calculator 
Students develop a simple program that: 
● Accepts income and expense details 
● Calculates savings 
● Categorizes expenses 
● Displays a summary report 
AI-Assisted Activity 
● Use AI to generate pseudocode and flowcharts from problem statements. 
● Compare human vs AI-generated solutions.

Expected Outcome 
Students demonstrate understanding of variables, loops, conditions, and functions.

# Module 4: React.js Frontend Development

● Navigation Bar 
● Cards 
● Forms 
● Modal Windows 
● Dashboard Widgets

Students consume data from APIs and dynamically display: 
● Student Lists 
● Product Catalogs 
● News Feeds

Outcome: Understanding data-driven UI development. 
Activity 3: State Management Challenge

● Counters 
● Task Managers 
● Expense Trackers
